### 4-1. 12장 마이페이지 — 동반 기록

**12~16장은 같은 틀을 씁니다.** 위에 프로필 카드(회원 · 대표 반려동물 · 통계 3개), 왼쪽에 메뉴 8개(동반 기록 · 반려동물 정보 수정 · 방문한 장소 · 작성한 후기 · 즐겨찾기 · 계정 관리 · 알림 설정 · 문의 내역), 가운데에 장마다 다른 내용입니다. 12장의 가운데는 「동반 기록」 입니다 — 정렬 칩 · 날짜별 묶음 · [AI 요약하기] · [삭제] · 빈 화면.

| 영역 | 명세서 | 실물 | 화면이 할 일 |
|---|---|---|---|
| ① | `GET /api/v1/users/me` | 같음 · `ProfileOutput` | 「{nickname} 회원님」 · 사진(서명 주소 · 없으면 기본 얼굴) · 이메일은 `GET /api/v1/auth/me` |
| ② | `GET /api/v1/pets` | 같음 | 대표 카드 — 사진 · 이름 · 견종 · 「몸무게: 3.5kg (소형견)」 · 「• {note}」 |
| ③ | (위 응답의 stats) | `visitCount` · `reviewCount` · `favoriteCount` | ⚠`reviewCount` 는 review 서버가 없어 늘 `null` — 작성한 후기는 브라우저 저장소의 내 후기 수 |
| ⑥ | `GET /api/v1/visits` | 같음 · `VisitCardOutput[]` 13칸 · 페이징 없음 | 날짜별로 묶음 — 묶음 제목은 (안) 「2024.10.04 (초록뜰 공원)」 처럼 날짜와 그날 첫 장소 |
| ⑦ | `POST /users/me/daily-summary` | `POST /api/v1/users/me/daily-summary` · `{visitDate ●}` → `{visitDate, summary (200자까지), generatedAt}` | [AI 요약하기] · 요약이 있으면 [갱신하기] |
| ⑧ | `DELETE /api/v1/visits/{visitId}` | 같음 · 없으면 404 `VISIT_NOT_FOUND` | [삭제] — 한 번 더 묻고 지움 |
| ④ | 계정 관리 (`PATCH /users/me` · 비밀번호 · 탈퇴) | 4/4 | 그림이 없는 화면 — 4/4 에서 다룸 |

**`VisitCardOutput`** 은 13칸입니다.

```
visitId · placeId · name · placeType · imageUrl · requiredItems [] · ratingAvg · visitedAt
petId · verdictAtVisit (방문 당시 판정) · memo · summary (그날 요약) · isFavorite
```

그날 요약(`summary`)은 하루 한 줄이라 **그날의 카드 중 하나에만 실립니다.** 화면은 날짜로 묶은 뒤 요약이 실린 카드에서 꺼내 묶음에 붙입니다. `ratingAvg` 는 늘 `null` 이라 평점은 브라우저 저장소의 평균을 씁니다.

---

**하루 요약의 제한**입니다. 그날 다녀온 곳도 담아 둔 곳도 없으면 쓸 말이 없어 버튼을 띄우지 않습니다.

| code | 뜻 | 문구 (안) |
|---|---|---|
| `SUMMARY_COOLDOWN` 429 | 같은 날짜를 60초 안에 다시 만듦 | 조금 전에 만들었어요. 1분 뒤에 다시 눌러 주세요. |
| `SUMMARY_DAILY_LIMIT` 429 | 계정당 하루 20번을 넘음 | 오늘 만들 수 있는 요약을 모두 만들었어요. 내일 다시 눌러 주세요. |
| `SUMMARY_GENERATION_FAILED` 502 | 모델 호출이 실패함 (하루 횟수는 되돌리지 않음) | 요약을 만들지 못했습니다. 잠시 후 다시 시도해 주세요. |

---

**정렬 칩**은 그림에 「전체 · 최근순 · 오래된 순 · 높은 평점순 · 낮은 평점순」 5개가 있습니다. 「전체」 와 「최근순」 이 같은 순서라 (안) 「전체」 를 처음 값(최근순)으로 두고 「최근순」 은 뺍니다. 평점순은 묶음 안 장소들의 평점 평균으로 가르고, 평점이 없는 묶음은 뒤로 보냅니다. 빈 화면은 그림대로 「아직 여행을 떠나지 않았어요」 입니다.
